# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。

### 树形放行链（`/release-chain`）

把设备节点、验收项、证书、缺陷和分支临时放行单接成逐级聚合的放行链，解决"汇流箱/逆变器缺证书或复测不合格时父级方阵、主变、并网点仍被继续办理"的问题：

- **逐级聚合**：每个节点聚合自身验收项/证书/缺陷与整棵子树，得出「具备条件 / 临时放行 / 阻断」三级状态，并沿父链向上传播。
- **最先出问题的子节点与依据**：阻断(block)优先、同级别按树先序定位到具体节点，页面给出根到该节点的完整路径、依据类别、标题、详情与版本号。
- **临时放行覆盖**：分支放行单把分支子树内的阻断夹成「临时放行」，但只在分支内生效、不向上游冒充具备条件；并网点最终签署仍校验"临时放行不等于阻断消除"。
- **依据变化即失效**：证书换版、验收项结果变化、已闭环缺陷重新打开都会比对签发时的版本指纹（`v版本:状态`）。子树仍阻断 → 放行单立即「已失效」并逐级重算；阻断已消除 → 进入「待确认」，负责人重新确认后续期，原临时放行才能继续。
- **同一分支唯一有效单**：两位负责人同时申请时经临界区串行化，只保留一张有效单，后到申请被拒绝并提示已存在单号。
- **事务与快照恢复**：所有变更走"草稿修改 → 重算 → 两阶段落盘（临时区回读校验后提交）"；写入中途失败时回滚内存并从最后完整树快照恢复，支持手动恢复与 TMP 残留清理。
- **旧数据父级补齐**：旧数据缺父级、父级悬空或层级倒挂时，按 并网点→变压器→方阵→逆变器→汇流箱 的现有层级就近补齐并记录修复日志，再参与计算。页面内置「导入缺父级旧数据」演练按钮。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
